---

## 🎯 Description

The dashboard provides an end-to-end, 7-page view of the customer journey — from acquisition through checkout to repeat purchase and post-purchase behavior:

- Executive Overview — headline KPIs, revenue & acquisition trends
- Acquisition & Channel Performance — CAC, LTV, LTV/CAC by channel
- Customer Lifecycle — time to second purchase, repeat behavior, LTV segmentation
- Retention Analysis — monthly cohort retention & repeat-rate trends
- Activation Funnel — Session → Browsing → Cart → Checkout → Repeat, with stage-wise drop-off
- Product & Category Performance — top products, category sales, discount impact, old vs. new SKUs
- Returns & Refund Analysis — order status distribution, return rate, delivered order trend
