
# 📊 Power BI Dashboard

This folder contains the Power BI dashboard file for the project.

---

## 📁 File

- ecommerce_dashboard.pbix

---

## 🎯 Description

The dashboard provides an end-to-end view of:

- Customer acquisition performance  
- Lifecycle behavior and repeat purchase trends  
- Cohort retention analysis  
- Activation funnel (Session → Repeat)  
- Marketing efficiency (LTV, CAC, LTV/CAC)  

---

## ⚙️ Requirements

- Microsoft Power BI Desktop

---
